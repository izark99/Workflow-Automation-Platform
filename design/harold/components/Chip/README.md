# Chip

A toggleable filter (`selected`) or a removable applied filter (`onRemove`). Pill shaped, 32px tall.

## Props

- `selected` (toggle chips, `aria-pressed`), `onRemove()` (removable chips, shows an x), `icon`, `onClick`.

## Rules

- Place filter chips in one row above the Table or list they filter. Selected chips use `primary-soft` with a `primary` border and a check.
- Use a "Thêm bộ lọc" chip with a `plus` icon to open more filters.
