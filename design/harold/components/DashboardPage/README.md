# DashboardPage

A worked example of a laptop webapp screen: Sidebar, TopBar with period switch and actions, four KpiTiles, a highlighted bar chart, a dense Table and an Alert. It loads with skeletons in the final layout, then fades in; the refresh button replays the loading state.

Use it as the reference layout for HR-System, Data Flow and the Budget planner: same skeleton on every page, content max 1200px, `space-5` gaps.
