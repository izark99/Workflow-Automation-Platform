# Icons

47 Lucide icons (v0.460.0, ISC license), 24 x 24 viewBox, 2px round stroke, no fill. The SVG files are single-ink in light ink (#f4f7fc, the dark theme `ink`) so they drop straight onto the dark Spatial scene; recolor the stroke for other grounds (#0f1a2b on light slides, `primary-text` #8cc4ff for highlights, #ffffff on blue fills).

In code, do not use these files: use `Harold.Icon` with the same names, which draws in `currentColor` and follows the theme.

- Navigation: `house`, `users`, `user`, `clock`, `wallet`, `briefcase`, `workflow`, `file-spreadsheet`, `chart-column`, `settings`, `bell`, `menu`, `log-out`
- Actions: `plus`, `minus`, `pencil`, `copy`, `trash-2`, `download`, `upload`, `play`, `refresh-cw`, `search`, `filter`, `list-filter`, `eye`, `ellipsis`, `x`, `check`
- Direction: `chevron-down`, `chevron-up`, `chevron-left`, `chevron-right`, `chevrons-up-down`, `arrow-up`, `arrow-down`, `trending-up`, `trending-down`
- Status: `info`, `circle-check`, `circle-alert`, `circle-x`, `triangle-alert`, `loader-circle`
- Time: `calendar`, `calendar-days`, `inbox`

Sizes: 16px in dense UI, 20px default, 24px on mobile and slides (36px on 1920-wide slides).
